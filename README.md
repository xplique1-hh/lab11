# Домашнее задание к работе 11

## Условие задачи
Создать структуру для хранения записи «Современный роман» (Вариант 26). Организовать ввод трех значений структур. Выполнить обработку 3 переменных структурного типа согласно варианту: отбор записей по условию.

**Поля записи:**
*   название
*   автор
*   количество страниц
*   средняя оценка по отзывам (от 0 до 10 баллов)
*   год издания

**Условие отбора:** Вывести данные о романах с количеством страниц от 100 до 200 и оценкой больше 5.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Установить русскую локаль и кодировку консоли (для корректного отображения кириллицы в Windows).
3. Объявить структуру `Roman` с полями: `name`, `author`, `pages`, `rating`, `year`.
4. Создать массив из 3 элементов типа `Roman`.
5. Вызвать функцию `input` для заполнения массива:
   - В цикле от 0 до 2 запросить у пользователя название, автора, количество страниц, оценку и год издания для каждого романа.
6. Вызвать функцию `show` для вывода результатов:
   - Инициализировать флаг `x = 0` (отвечает за проверку наличия подходящих записей).
   - В цикле от 0 до 2 проверить условие: `pages >= 100` И `pages <= 200` И `rating > 5`.
   - Если условие выполняется, вывести данные романа и установить `x = 1`.
   - После цикла, если `x == 0`, вывести сообщение "Подходящих романов нет".
7. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <locale.h>
#include <stdio.h>
#include <windows.h>

struct Roman {
    char name[50];
    char author[50];
    int pages;
    double rating;
    int year;
};

void input(struct Roman r[], int n) {
    for (int i = 0; i < n; i++) {
        printf("\nРоман %d\n", i + 1);
        printf("Название: ");
        scanf(" %49[^\n]", r[i].name);
        printf("Автор: ");
        scanf(" %49[^\n]", r[i].author);
        printf("Количество страниц: ");
        scanf("%d", &r[i].pages);
        printf("Средняя оценка (0-10): ");
        scanf("%lf", &r[i].rating);
        printf("Год издания: ");
        scanf("%d", &r[i].year);
    }
}

void show(struct Roman r[], int n) {
    int x = 0;
    for (int i = 0; i < n; i++) {
        if (r[i].pages >= 100 && r[i].pages <= 200 && r[i].rating > 5) {
            printf("%s, %s, %d стр., оценка %.1f, %d г.\n",
                r[i].name, r[i].author, r[i].pages, r[i].rating, r[i].year);
            x = 1;
        }
    }
    if (!x) printf("Подходящих романов нет\n");
}

int main() {
    setlocale(LC_ALL, "RUS");
    SetConsoleCP(1251);
    SetConsoleOutputCP(1251);
    struct Roman r[3];
    input(r, 3);
    printf("\nРезультат:\n");
    show(r, 3);
    return 0;
}
```
